== Quartz Scheduler

Quartz is a job scheduling library. This repository is a single Maven project
for scheduling and executing jobs.

== This fork (3.0)

* Requires **Java 26**.
* Both `RAMJobStore` and `MongoJobStore` implement `org.quartz.spi.JobStore` as siblings (Mongo composes RAM; it does not extend it).
* Persistent store is **MongoDB only** (`org.quartz.impl.mongodb.MongoJobStore`). JDBC / RDBMS support has been removed.
* Public fire times use `java.time.Instant` (not `java.util.Date`). `DateBuilder` is the DSL helper that produces those instants (`futureDate`, `tomorrowAt`, `evenMinuteDate`, …) and takes `ZoneId`, not `TimeZone`.
* Clustering needs a MongoDB replica set and NTP-synced clocks.
* Keep the official `spring-boot-starter-quartz` off the classpath (it still assumes JDBC).
  This artifact ships its own auto-configuration. Inject Boot's `MongoClient` (it is not closed
  by the job store).

YAML (in the Spring Boot application):

```
spring:
  quartz:
    job-store-type: auto          # mongodb if a MongoClient bean exists, otherwise ram
    scheduler-name: quartzScheduler
    auto-startup: true
    wait-for-jobs-to-complete-on-shutdown: true
    thread-pool:
      thread-count: 10
    mongodb:
      # database: oxneer     # optional; defaults to spring.mongodb.database
      collection-prefix: qrtz_
      clustered: true            # replica set + NTP
    # properties:
    #   org.quartz.threadPool.threadCount: "10"
```

Declare `JobDetail`, `Trigger`, and `Calendar` beans in the app; they are registered automatically.
Jobs are constructed per fire and autowired from the Spring context.

Build:

```
mvn test
```

Example:

```
org.quartz.jobStore.class=org.quartz.impl.mongodb.MongoJobStore
org.quartz.jobStore.mongoUri=mongodb://localhost:27017
org.quartz.jobStore.dbName=quartz
org.quartz.jobStore.isClustered=true
org.quartz.scheduler.instanceId=AUTO
```
